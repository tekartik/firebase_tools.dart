# firebase_tools.dart

Firebase developer tools for dart: emulator control, project build/deploy and
an explorer (auth users, firestore, storage) usable from a `dev_build` console
menu.

## Packages

| Package | Path | Description |
| --- | --- | --- |
| [tekartik_firebase_tools](packages/firebase_tools) | `packages/firebase_tools` | The admin sdk flavour and the main dev menu — **depend on this one** |
| [tekartik_firebase_tools_common](packages/firebase_tools_common) | `packages/firebase_tools_common` | The same tools on the firebase abstractions only, no implementation picked |
